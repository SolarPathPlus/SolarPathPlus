## 🧩 SolarPath+ Ecosystem & Repositories

This is the main hub repository for the SolarPath+ project. Below are the links to the active sub-projects and components that form the ecosystem:

* 📦 **[Arc (Package Registry)](https://github.com/SolarPathPlus/arc/):** Central repository hosting package recipes, SHA256 checksums, and source URLs.
* ⚙️ **[tig-pkg (Package Manager)](https://github.com/SolarPathPlus/tig-pkg/):** C++ based package manager engine that parses recipes from Arc and handles installations.
* 🛠️ **[Admin Panel](https://github.com/SolarPathPlus/admin-panel/):** Administrative control interface for managing packages, system resources, and repositories.
* 👤 **[User Panel](https://github.com/SolarPathPlus/user-panel/):** Interface allowing users to discover packages and manage their account settings.
* 🌐 **[Project Information Site](https://github.com/SolarPathPlus/solarpathplus.github.io/):** Open-source web platform containing documentation and introduction for the ecosystem.
