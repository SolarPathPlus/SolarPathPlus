# SolarPathPlus

SolarPath+ is an eco-friendly urban lighting project carried out by the Intergalactic (TIG) team, formed by four entrepreneurs from Turkey, and actively developed as of 2026. The project modernizes urban lighting infrastructures in a smart and modular structure, adopting ease of implementation and integration as its core principles.

The system is supported by its own custom software packages, a package manager (tig-pkg) used to manage this ecosystem, and a web platform where details can be examined.

This repository serves as the main hub and navigation point for accessing all sub-projects, components, and resources belonging to the SolarPath+ ecosystem. In line with the open sharing principles adopted by the TIG team, SolarPath+ offers a completely open-source development model. Circuit designs, external software repositories (such as the package manager), and all other components can be accessed via the links provided in this repository. (Note: As the project is in the development phase, it may contain incomplete parts.)

The project's development process is ongoing, with the goal of releasing its first working prototype (v1.0.0) by the end of the year.
